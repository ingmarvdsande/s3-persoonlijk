# Non-functionele requirements

| NFR1  | Snelheid meten en displayen         |
| ----- | ------------------|
| Omschrijving | Het systeem moet in staat zijn om de snelheid van een persoon te meten en weer te geven in meters per seconde (m/s). |
| Rationale | Dit is cruciaal voor het meten en vergelijken van prestaties. |
| Business Priority | Must have |

| NFR2  | Hoogste snelheid op leaderboard        |
| ----- | ------------------|
| Omschrijving | Alleen de hoogste snelheid van elke persoon moet op het leaderboard worden weergegeven. |
| Rationale | Dit zorgt ervoor dat alleen de beste prestaties zichtbaar zijn, wat de competitie vergroot. |
| Business Priority | Must have |

| NFR3  | Uptime         |
| ----- | ------------------|
| Omschrijving | Het systeem moet een uptime hebben van minimaal 90%. |
| Rationale | Een betrouwbare werking is essentieel voor continue beschikbaarheid en gebruik en voor het gebruikersgemak, zo hoeven de verzorgers zich niet druk te maken om regelmatige troubleshooting of opnieuw opstarten. |
| Business Priority | Must have |

| NFR4  | Backend-omgeving         |
| ----- | ------------------|
| Omschrijving | De backend moet draaien op Ubuntu 22.04 of een recentere versie. |
| Rationale | Ubuntu 22 biedt een stabiele en veilige omgeving voor serverapplicaties. Daarnaast is dit een vereiste vanuit de oprachtgever |
| Business Priority | Must have |

| NFR5  | Smiley display op basis van snelheid         |
| ----- | ------------------|
| Omschrijving | Het scherm kan een smiley tonen afhankelijk van de gemeten snelheid. |
| Rationale | Dit verhoogt de gebruikservaring en maakt het systeem leuker in gebruik. |
| Business Priority | Could have |

| NFR6  | Leaderboard design in CSS        |
| ----- | ------------------|
| Omschrijving | Het leaderboard moet worden ontworpen met behulp van CSS. |
| Rationale | Dit zorgt voor een visueel aantrekkelijk design. Daarnaast is dit een vereiste vanuit de opdrachtgever|
| Business Priority | Could have |

| NFR7  | Intuïtieve gebruikersinterface        |
| ----- | ------------------|
| Omschrijving | De gebruikersinterface moet intuïtief en gemakkelijk te begrijpen zijn. |
| Rationale | Een gebruiksvriendelijke interface verbetert de toegankelijkheid voor alle gebruikers. |
| Business Priority | Could have |

| NFR8  | Beloningen voor unieke prestaties        |
| ----- | ------------------|
| Omschrijving | Het systeem kan beloningen toekennen voor unieke prestaties van gebruikers. |
| Rationale | Dit stimuleert gebruikers om zich meer in te spannen en voegt een spelelement toe. |
| Business Priority | Could have |
